#  Simple Web Calculator

მარტივი, მოსახერხებელი და დახვეწილი დიზაინის მქონე ვებ-კალკულატორი, შექმნილი HTML, CSS და JavaScript-ის გამოყენებით.

##  ფუნქციონალი (Features)
*  ძირითადი მათემატიკური ოპერაციები (მიმატება, გამოკლება, გამრავლება, გაყოფა).
*  სუფთა და ადაპტური დიზაინი (Responsive UI).
*  ეკრანის გასუფთავების (Clear) ფუნქცია.
* ⌨ კლავიატურიდან ციფრებისა და ოპერატორების შეყვანის მხარდაჭერა.

##  ტექნოლოგიები (Tech Stack)
* **HTML** - სტრუქტურა
* **CSS** - სტილები და დიზაინი
* **JavaScript** - გამოთვლების ლოგიკა
